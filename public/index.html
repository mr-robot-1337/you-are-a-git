    Git & Sandbox Commands

    git initCreate empty Git repo
    touch / edit / catCreate, edit, or view file
    git status / diffInspect working tree & diffs
    git add <file|.>Stage file(s) (or resolve)
    git restore [--staged]Discard changes or unstage
    git commit -m "msg"Record staged snapshot
    git switch [-c] <br>Switch (or create) branch
    git branch [name]List or create branches
    git merge <branch>Merge branch into HEAD
    git rebase <branch>Replay commits onto branch
    git stash [pop|list]Stash or restore dirty work
    git reset --hard <ref>Move branch pointer to ref
    git revert HEADCreate inverse undo commit
    git reflog / logView reflog or commit history
    git fsckDiagnose repo corruption
